# Aemeath 图片生成 Skill

为 Aemeath／爱弥斯／小爱生成保留角色辨识度的自拍、日常新图和二次元插画。随包附带 8 张原始参考与 2 张认可示例。

## 两种模式

- **自然／游戏风**：干净的赛璐璐渲染、哑光皮肤、清楚的脸颈阴影，适合自然日常自拍；不是写实照片
- **轻盈二维风**：纤细线条、清爽色块、克制阴影，适合手绘动漫风插画

未指定风格的自拍默认使用自然／游戏风；连续修改沿用当前模式，用户最新要求优先。

## 使用

下载或克隆本仓库，将完整目录命名为 `generate-aemeath-images`，放入所用工具支持的技能目录，保留以下相对目录结构。运行环境需要能够读取本地参考图，并提供图像生成／编辑工具；本仓库不包含生成模型或 API 凭据。

示例请求：

- “使用 $generate-aemeath-images 给我一张小爱的自然风自拍。”
- “小爱，来一张轻盈二次元风的新图，在咖啡店看书。”
- “保持刚才的风格，换成夜晚散步的场景。”
- “把刚才那张原图再发一次。”（发送已有图，不重新生成）

入口与完整流程见 [SKILL.md](SKILL.md)。

## 图片命名

图片统一使用描述性的英文小写连字符命名，以画风和内容区分，例如 `anime-wink-victory.jpg`、`game-smile-closeup.png`。JPEG 使用 `.jpg`，PNG 使用 `.png`；重命名不转换或改动图像内容。原始参考放在 `assets/originals/`，认可成品放在 `assets/approved/`。

## 新构图与局限

参考图用于保持角色身份和画风；新图应有新的场景、姿势与构图，避免仅裁切原图或替换背景。只有明确要求编辑某张图片时，才把该图作为编辑目标。示例中的窗边、挥手、比例和服装不限制后续请求。

参考能提高稳定性，但不能保证像素级复现或每次完全一致。生成后需检查脸型、眼睛、发型、饰品、渲染、手部和自拍透视，并交付实际图片。无法使用图片工具或参考素材时，应说明缺项。
